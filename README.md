Studio DRYKA SPINDOLA
Bem-vindo ao repositório do site Studio DRYKA SPINDOLA! Este projeto é um site para um estúdio de beleza e barbearia, apresentando informações sobre serviços, galeria de fotos e vídeos, contato e localização.

📋 Descrição
O site foi desenvolvido para promover o Studio DRYKA SPINDOLA, destacando:

História do estúdio e sua fundadora.
Serviços e preços oferecidos.
Galeria de fotos e vídeos de cortes e estilos.
Informações de contato e localização no Google Maps.
Tema claro e escuro para melhor experiência do usuário.
📂 Estrutura do Projeto
Arquivos Principais
index.html: Estrutura principal do site.
style.css: Estilos para o layout e design.
script.js: Funcionalidades interativas, como alternância de tema e menu responsivo.
Seções do Site
Home: Apresentação do estúdio.
Sobre Nós: História inspiradora da fundadora.
Serviços: Tabela com serviços e preços.
Galeria: Fotos e vídeos de cortes e estilos.
Contato: Informações de contato, botão do WhatsApp e mapa de localização.
🚀 Funcionalidades
Tema Claro/Escuro: Alternância entre temas para melhor acessibilidade.
Galeria Responsiva: Exibição de imagens e vídeos com design adaptável.
Tabela de Serviços: Lista de serviços com preços organizados.
Botão do WhatsApp: Link direto para agendamento via WhatsApp.
Mapa Integrado: Localização do estúdio via Google Maps.
📸 Pré-visualização
Galeria
A galeria exibe imagens e vídeos de cortes e estilos realizados no estúdio.
